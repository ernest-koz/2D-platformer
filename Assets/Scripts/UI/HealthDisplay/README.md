# Health Display

Универсальная система отображения здоровья для Unity (UGUI + TextMeshPro).
Подписывается на события ранее реализованного компонента `Health`
(см. `Assets/Scripts/Common/Health.cs`) и не содержит собственной
логики здоровья.

## Состав

| Компонент | Назначение |
|-----------|------------|
| `HealthView` | Базовый класс. Хранит ссылку на `Health`, подписывается на `Health.Changed` в `OnEnable`, отписывается в `OnDisable`, первый рендер выполняет в `Start`. |
| `HealthText` | Текстовый индикатор в формате `Текущее здоровье/Максимальное здоровье` (например, `45/100`). |
| `HealthBar` | Бар здоровья на компоненте `Slider`: `maxValue = максимум`, `value = текущее` — заполнение обновляется мгновенно. |
| `SmoothHealthBar` | Наследник `HealthBar`: значение слайдера движется к целевому через `Mathf.MoveTowards` со скоростью `_fillSpeed` (HP/сек). |
| `HealthSimulator` | Тестовый помощник для демо-сцены: методы `TakeDamage()` и `Heal()` для кнопок (имитация ударов врагов и подбора аптечек). |

## Подключение в своём проекте

1. На объекте с состоянием здоровья должен быть компонент `Health`.
2. Добавьте нужные индикаторы (`HealthText`, `HealthBar`, `SmoothHealthBar`) —
   можно все сразу на один экземпляр `Health`.
3. В инспекторе назначьте ссылку на `Health` и виджет
   (`TMP_Text` для текста, `Slider` для баров).
4. Индикаторы сами подписываются на `Health.Changed` — дополнительно
   связывать их с `Health` кодом не нужно.

## Зависимости

- Компонент `Health` с событием `Changed(int current, int maximum)` и
  свойствами `Current`/`Maximum`. При экспорте пакета он включается как
  зависимость; если в целевом проекте уже есть свой `Health` — снимите
  галочку с `Health.cs` при импорте.
- `com.unity.ugui` (Slider, Button) и `com.unity.textmeshpro` (TMP_Text).

## Демо-сцена

`Assets/HealthDisplayDemo.unity` — один экземпляр `Health` (100 HP),
три индикатора и две кнопки («Урон −10», «Лечение +10»), которые вызывают
`HealthSimulator`. Неуязвимость после удара отключена (`Invincibility Time = 0`),
чтобы кнопки работали подряд без задержки.

Пакет для переиспользования: `HealthDisplay.unitypackage` в корне проекта.
Пересоздать сцену и пакет можно через меню
`Tools → Health Display → Build Demo Scene` или метод
`HealthDisplayDemoBuilder.Build`.
